🗄️ 数据库表结构

表名 说明 主要字段
evaluations 评测任务表 id model_id dataset_ids status config
models 模型定义表 id name type provider
datasets 数据集定义表 id name description config_template
results 评测结果表 evaluation_id accuracy metrics summary

🔄 完整评测流程

1️⃣ 创建评测任务

用户发送 POST /api/v1/evaluations
→ API 验证请求
→ 创建数据库记录 (status=pending)
→ 设置 Redis 缓存 (ttl=24h)

2️⃣ 启动 K8s Job

→ 后台 goroutine 触发
→ 创建 ConfigMap (OpenCompass 配置)
→ 创建 Secret (API Keys)
→ 创建 Job Pod
→ 更新状态 (status=running)

3️⃣ 执行 OpenCompass

Pod 内执行: python run.py
→ 调用 LLM API 评测
→ 生成预测结果
→ 写入输出目录

4️⃣ 收集与存储结果

→ 解析 JSON 预测结果
→ 提取 CSV 汇总
→ 存储到 PostgreSQL
→ 更新状态 (status=completed)

5️⃣ 清理资源

→ 删除 K8s Job
→ 删除 ConfigMap
→ 删除 Secret
→ 保留数据库记录
