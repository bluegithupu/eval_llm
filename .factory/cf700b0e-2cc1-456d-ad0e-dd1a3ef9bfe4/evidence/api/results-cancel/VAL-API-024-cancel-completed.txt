VAL-API-024: Cancel Already Completed Task
When DELETE request is made for an already completed task, the system returns HTTP 409 Conflict indicating task cannot be cancelled.

=== TEST: DELETE /api/v1/evaluations/8bb55603-42f1-4056-b073-6f805fcd5114 ===

Request:
curl -s -X DELETE -w "\nHTTP_STATUS:%{http_code}" http://localhost:3100/api/v1/evaluations/8bb55603-42f1-4056-b073-6f805fcd5114

Response:
{
  "error":"cannot cancel completed evaluation"
}
HTTP_STATUS:409

Result: PASS
- DELETE returns HTTP 409 Conflict
- Error message indicates task cannot be cancelled because it's completed
