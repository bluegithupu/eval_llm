VAL-API-021: Results Not Ready
When GET request is made for a task that is not yet completed (pending, running), the system returns HTTP 409 Conflict or HTTP 425 Too Early.

=== TEST: GET /api/v1/evaluations/765ad646-6afa-40aa-aa86-ffa15a18f520/results ===

Request:
curl -s -w "\nHTTP_STATUS:%{http_code}" http://localhost:3100/api/v1/evaluations/765ad646-6afa-40aa-aa86-ffa15a18f520/results

Response:
{
  "error":"results not available: evaluation is pending"
}
HTTP_STATUS:409

Result: PASS
- Status code: 409 (Conflict)
- Error message indicates results not ready
